Why do computers sort things?

Sorting puts data into a useful order so that people and programs can organise, compare and search it more easily. Different algorithms can produce the same sorted result while doing different amounts of work.

Bubble Sort

COMPARE NEIGHBOURS → SWAP IF NEEDED → MOVE RIGHT

Repeatedly compares adjacent values. Large values gradually move towards the right.

Selection Sort

MARK MINIMUM → SCAN REMAINING VALUES → SWAP ONCE

Finds the minimum in the unsorted section, then places it into the next finished position.

Quick Sort

CHOOSE PIVOT → PARTITION → SORT OUTER GROUPS → JOIN

Uses a pivot to split values into LESS, EQUAL and GREATER groups, then sorts the outer groups recursively.

Key terminology

Algorithm
A precise sequence of steps for solving a problem.
Comparison / scan
Looking at values to decide what should happen next.
Swap
Exchanging the positions of two cards.
Pivot
The Quick Sort reference value used to divide cards into LESS, EQUAL and GREATER groups.
Partition
Classifying a Quick Sort group around its pivot.
Recursion
Applying the same sorting process again to smaller groups.

Efficiency — how much work?

Efficiency describes how the amount of work grows as the list gets larger. We often write this using Big O notation.

AlgorithmTypical ideaEfficiencyWhat to notice
Bubble SortRepeated neighbour comparisonsUsually O(n²)Simple to understand, but work grows quickly on large lists.
Selection SortScan the unsorted section for its minimumO(n²)Still performs many comparisons, but normally only one swap per round.
Quick SortPartition around pivotsAverage O(n log n); worst O(n²)Good pivots tend to create balanced groups; poor pivots can create uneven groups.

For our five-card classroom example: focus first on accurately counting comparisons/scans, swaps and partitions. Big O describes how the algorithm scales when the input becomes much larger.
